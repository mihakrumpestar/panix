# Security

## Reporting a vulnerability

Please email **security@mihakrumpestar.com** instead of opening a public issue or discussion. Reports should include:

- what the issue is and where it lives
- how to reproduce it
- the impact you expect
- any suggested fix or extra context

## After a report

Every report is acknowledged and reviewed. Because panix is maintained by a single developer, fixed response timelines cannot be promised, but reporters will be kept informed.

When a fix ships, the report is mentioned in the release notes and credited by name or handle, unless anonymity is requested.

## Disclosure

Please keep the issue private until a fix is available. Fixes ship first, and the report is mentioned in the release notes afterward. A public write-up can be arranged once the timing is agreed.

Thank you for helping to keep Panix users safe.

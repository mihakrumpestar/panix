Your infrastructure may span multiple flakes and repositories. A Panix fleet can reference any number of them:

```yaml
fleet:
  flakes:
    infrastructure:
      url: path:../infra-flake
      installables:
        nixosConfigurations:
          servers:
            machines:
              server-01:
              server-02:

    monitoring:
      url: github:myorg/monitoring-flake
      installables:
        nixosConfigurations:
          prometheus:
            machines:
              prom-01:

    secrets-management:
      url: git+ssh://git@github.com/myorg/vault-nixos
      installables:
        nixosConfigurations:
          vault:
            machines:
              vault-01:
```

Each flake builds independently, and each installable deduplicates builds across its machines. See the [configuration model](/concepts/configuration-model/) for how installables and machines relate.

## Flake URL Schemes

Panix supports several URL schemes for flake references:

| Scheme | Example | Description |
|--------|---------|-------------|
| `path:` | `path:../infra-flake` | Local filesystem path |
| `github:` | `github:myorg/repo` | GitHub repository |
| `github:owner/repo#ref` | `github:myorg/repo#main` | GitHub repo at specific ref |
| `git+ssh://` | `git+ssh://git@github.com/myorg/repo` | Git over SSH |
| `ssh:` | `ssh://myorg@host/repo` | A remote flake over SSH |
| `.` (default) | Omit `url` field | Current directory |

When `url` is omitted, it defaults to `"."` (current directory).

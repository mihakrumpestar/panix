Panix supports tab completion for commands, flags, and flag values in **bash**, **zsh**, and **fish**.

## Install

Manual:

import { Tabs, TabItem } from '@astrojs/starlight/components';

<Tabs>
<TabItem label="bash">

```sh
echo 'source <(panix completion -c bash)' >> ~/.bashrc
```

</TabItem>
<TabItem label="zsh">

```sh
echo 'source <(panix completion -c zsh)' >> ~/.zshrc
```

</TabItem>
<TabItem label="fish">

```sh
echo 'panix completion -c fish | source' >> ~/.config/fish/config.fish
```

</TabItem>
</Tabs>

Run `panix completion` with no shell argument to auto-detect. Use `-c` to print raw shell code for piping.

## Nix / Home Manager

When Panix is installed via the Nix flake, shell completions are installed
automatically using `installShellFiles`. No manual sourcing is needed; just
make sure your shell is enabled:

```nix
# Home Manager
programs.bash.enable = true;   # or programs.zsh.enable / programs.fish.enable
```

```nix
# NixOS
programs.bash.enable = true;   # or programs.zsh.enable / programs.fish.enable
```

:::note
Completions are generated at build time and placed in the standard
`share/bash-completion/completions/`, `share/fish/vendor_completions.d/`, and
`share/zsh/site-functions/` directories. Enabling the corresponding shell
program is sufficient; there is no need to edit init files.
:::

## Troubleshooting

**Completion doesn't work:**
  
- Ensure `panix` is on `$PATH` and the init line is in the correct file (`~/.bashrc`, `~/.zshrc`, or `~/.config/fish/config.fish`). Restart your terminal or `source` the file.

**zsh: `compdef: command not found`:**
  
- Load `compinit` before the panix line:

  ```zsh
  autoload -Uz compinit && compinit
  source <(panix completion -c zsh)
  ```

All flags can also be set via environment variables (shown in parentheses) or in the `flags` section of `panix.yml`.

## Runtime Tunables

The `--runtime.*` flags configure operational timeouts and concurrency. They can be set via CLI flag, environment variable, or the `runtime:` block under `flags` in `panix.yml`.

| Flag | Env var | Default | Description |
|------|---------|---------|-------------|
| `--runtime.max-concurrency` | `PANIX_RUNTIME_MAX_CONCURRENCY` | `1000` | Max parallel workers in the worker pool |
| `--runtime.disconnect-timeout` | `PANIX_RUNTIME_DISCONNECT_TIMEOUT` | `5m` | Wait for host to disconnect during reboot |
| `--runtime.reconnect-timeout` | `PANIX_RUNTIME_RECONNECT_TIMEOUT` | `10m` | Wait for host to reconnect after reboot |
| `--runtime.ssh-reachability-timeout` | `PANIX_RUNTIME_SSH_REACHABILITY_TIMEOUT` | `2s` | TCP dial timeout for SSH reachability probe |
| `--runtime.flake-validation-timeout` | `PANIX_RUNTIME_FLAKE_VALIDATION_TIMEOUT` | `60s` | Timeout for nix flake metadata/eval during validation |

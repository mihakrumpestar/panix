title: Keybinds
description: Quick reference for all TUI keyboard shortcuts.
sidebar:
  order: 2
---

| Key | Action |
|-----|--------|
| `r` | Retry failed phases (unavailable with `--require-all-success`) |
| `ctrl+r` | Restart entire workflow (does not reread the yaml config; unavailable with `--require-all-success`) |
| `m` | Toggle logs fullscreen |
| `esc` | Exit fullscreen, or deselect the selected build log viewport |
| `ctrl+c` | Copy active build logs label or command output to clipboard |
| `c` | Toggle labels between descriptions and raw commands |
| `h` | Toggle to include `inspect` and `secrets` phases in the build logs |
| `a` | Show only active/errored build logs |
| `left`/`right` | Navigate between stats table or phase status entries |
| `mouse click` | Select an entry from stats table, phase status, build logs (selecting selected stats table or phase status deselects them) |
| `mouse scroll`/`up`/`down`/`j`/`k`/`pgup`/`pgdown` | Scroll main view or inner view when selected |
| `s` | Take a snapshot of current workflow state (not available in snapshot view) |
| `q` | Quit (sends stop signal to commands and waits for them to finish, then exits) |
| `ctrl+q` | Force quit immediately |

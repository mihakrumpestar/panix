| Key | Action |
|-----|--------|
| `r` | Retry failed phases |
| `ctrl+r` | Restart entire workflow (does not reread the yaml config) |
| `m` | Toggle logs fullscreen |
| `ctrl-c` | Copy active build logs label or command output to clipboard |
| `c` | Toggle labels between descriptions and raw commands |
| `h` | Toggle to include `inspect` and `secrets` phases in the build logs |
| `a` | Show only active/errored build logs |
| `left`/`right` | Navigate between stats table or phase status entries |
| `mouse click` | Select an entry from stats table, phase status, build logs |
| `mouse scroll`/`up`/`down` | Scroll main view or inner view when selected |
| `s` | Take a snapshot of current workflow state |
| `q` | Quit (sends stop signal to commands and waits for them to finish, then exits) |
| `ctrl+q` | Force quit immediately |

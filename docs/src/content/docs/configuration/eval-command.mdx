The `eval` command fully evaluates and validates the configuration, preparing it for execution.

```sh
panix eval                    # Output to stdout (colorized)
panix eval -o processed.yaml  # Output to file (plain YAML)
```

## What it Does

Everything [panix template](/configuration/template-command/) does, plus:

- Loads and validates the full configuration
- Validates flake URLs and configuration keys (`--validate.flakes`)
- Validates bootstrap disk encryption key local paths (`--validate.bootstrap-secrets`)
- Resolves inherited attributes, tags, and secrets
- Filters out disabled and untagged parts of the configuration
- Outputs the fully resolved configuration

## Validation Flags

```sh
panix eval --validate.flakes              # Validate flake URLs and configuration keys
panix eval --validate.bootstrap-secrets   # Validate bootstrap disk encryption key local paths exist
panix eval --validate.flakes --validate.bootstrap-secrets  # Both
```

## Use Cases

- Validate configuration before deploying
- See the fully resolved configuration after inheritance and tag filtering
- Debug inheritance issues (which secrets, tags, and settings each machine receives)
- CI/CD pipeline validation step

Panix is configured through a single YAML file (default: `panix.yml`) that defines your fleet structure, SSH connections, build options, and deployment targets.

## Fleet Tree

The core of the file is the fleet tree: flakes contain installables, installables contain machines, and settings cascade down each level.

```yaml
fleet:
  flakes:
    my-flake:
      installables:
        nixosConfigurations:
          webserver: { machines: { web-01: } }
```

See the [Quick Start](/getting-started/) for a full minimal configuration, and the [configuration model](/concepts/configuration-model/) for how inheritance works across the tree.

## Top-Level Keys

| Key | Purpose |
|-----|---------|
| `flags` | Global flags: activation mode, output mode, TUI settings, logging, snapshots, profiling. All overridable via CLI arguments |
| `output_types` | Custom output type presets, applied as defaults to installables of that type |
| `fleet` | Fleet definition: flakes, installables, machines, SSH, secrets, nix options |

## 1. Run directly

The simplest way to run Panix without installing:

```sh
nix run github:mihakrumpestar/panix -- deploy
```

## 2. Add to your flake

Add Panix as a flake input and include it in your system packages:

```nix
{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";

    panix.url = "github:mihakrumpestar/panix";
  };

  outputs = { self, nixpkgs, panix, ... }@inputs: {
    nixosConfigurations.my-server = nixpkgs.lib.nixosSystem {
      system = "x86_64-linux";
      modules = [
        ./configuration.nix
        {
          environment.systemPackages = [
            panix.packages.${system}.default
          ];
        }
      ];
    };
  };
}
```

:::note[Binary cache]
CI pushes build results to a Cachix cache, so prebuilt binaries are available instead of compiling from source (which takes about 10s to build on mid-range hardware). To use it, add the cache to your own flake:

```nix
{
  nixConfig = {
    extra-substituters = [ "https://mihakrumpestar.cachix.org" ];
    extra-trusted-public-keys = [ "mihakrumpestar.cachix.org-1:7mKgpsk+9+iJcaT5DwvUtMxlJS+1GH/dlYhzoFkefJg=" ];
  };
}
```
:::

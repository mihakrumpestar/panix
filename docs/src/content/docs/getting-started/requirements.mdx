## Requirements

- **Nix**: Panix uses `nix` found in PATH. It also uses common utilities: `uname`, `id`, `echo`, `cat`, `readlink`, `curl`, `tar`
- **rsync**: Required on both local and remote for file transfers (included in kexec images)
- **kexec memory**: Minimum 1GB RAM without swap for kexec bootstrap
- **SSH key auth**: Only SSH key authentication is supported, no password auth
- **Flake-only**: Only Nix flakes are supported

## Lix Support

[Lix](https://lix.systems) is a fork of Nix that Panix detects and supports automatically. When Lix is detected on the local machine, Panix adjusts:

- nix store URL format (Lix uses `?port=N` query params instead of `:port` in the host).

:::caution
If your local machine runs Lix, but the remote machine runs Nix (or vice versa), remote build mode (`build_mode: remote`) may encounter store URL format mismatches. This has not been tested. If you run into issues, please [open a GitHub issue](https://github.com/mihakrumpestar/panix/issues).
:::

Local build mode works without issues in mixed environments.

## Caveats

- **Nix store location**: Panix expects the Nix store to be in the standard location (`/nix/store`). If it is not, you will have to specify it using `nix` CLI args in Panix config.
- **Nix store locking**: concurrent building of exact same packages is not allowed in store, so some builds may show a `waiting for store lock` warning briefly until the lock is released.

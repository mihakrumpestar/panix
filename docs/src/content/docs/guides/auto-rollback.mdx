Automatic rollback is now part of the Activation Guard, which replaces `auto_rollback` with the `rollback` tier attribute (`off`, `auto`, or `magic`) and adds health checks, bounded timeouts, and self-healing reverts.

See [Activation Guard](/guides/activation-guard/).
